# AquaWatch — Freshwater Ecological Status Prediction

A machine learning pipeline that predicts freshwater ecological status 
(Poor, Moderate, Good) from citizen science observational data, without 
requiring chemical testing.

---

## Project Overview

This project trains and evaluates five classification models on a global 
citizen science freshwater monitoring dataset. The goal is to determine 
whether ecological status can be predicted from purely visual field 
observations — water colour, algae presence, land use, aquatic life, 
vegetation, flow, and level.

Models evaluated:
- Random Forest
- XGBoost
- Support Vector Machine (LinearSVC)
- K-Nearest Neighbours (KNN/WNN)
- Multilayer Perceptron (Neural Network)

## Requirements: 
- pandas
- numpy
- scikit-learn
- matplotlib
- xgboost
